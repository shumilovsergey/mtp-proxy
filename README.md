# MTProto Proxy

Трафик маскируется под обычный HTTPS (fake-TLS) — выглядит как обычное соединение на порт 443.

**Стек:** [mtg v2](https://github.com/9seconds/mtg) (Go) + Docker Compose.

> **Важно:** прокси занимает порт `443`. Если на сервере уже крутится nginx или что-то другое на этом порту — останови перед запуском.

---

## Быстрый старт

**1. Сгенерируй секрет:**
```bash
docker run --rm nineseconds/mtg:2 generate-secret --hex www.google.com
```
Скопируй вывод (начинается с `ee`) и вставь в `mtg.toml`:
```toml
secret = "eeВАШ_СЕКРЕТ"
```

**2. Запусти:**
```bash
docker-compose up -d
```

**3. Получи ссылку для подключения:**
```bash
docker exec mtg-proxy /mtg access /etc/mtg.toml
```

Выдаст ссылку вида `tg://proxy?server=...` — отправь её пользователям.

---

## Подключение на устройствах

**Мобильный (iOS / Android):**
просто нажми на ссылку `tg://proxy?...` на своем устройстве.

**Десктоп / вручную:**
Настройки → Конфиденциальность → Использовать прокси → Добавить → MTProto
- **Сервер:** IP сервера
- **Порт:** `443`
- **Секрет:** строка `ee...`
